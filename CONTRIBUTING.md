# Contributing

Endcord Desktop's code is developed in [Endcord's repository](https://github.com/Endcord/Endcord). The app is in [`desktop/`](https://github.com/Endcord/Endcord/tree/main/desktop) there, and the rest of that repository is the Endcord it loads. Open pull requests there, following [Endcord's contributing guide](https://github.com/Endcord/Endcord/blob/main/CONTRIBUTING.md).

This repository holds the app's issues and README.

- **Found a bug in the app?** Open a [bug report](https://github.com/Endcord/EndcordDesktop/issues/new/choose) here.
- **Have an idea for the app?** Open a feature request here.
- **Want a new plugin?** Ask on the [Endcord server](https://discord.gg/endcord).

Everyone taking part follows the [Code of Conduct](CODE_OF_CONDUCT.md).
