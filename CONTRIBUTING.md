# Contributing

This repository is Endcord Desktop's home: its code, releases and issues. Endcord itself, the mod with its plugins and settings, is in [Endcord's repository](https://github.com/Endcord/Endcord).

- **Found a bug in the app?** Open a [bug report](https://github.com/Endcord/EndcordDesktop/issues/new/choose) here.
- **Have an idea for the app?** Open a feature request here.
- **Want to change the app's code?** Pull requests for what's in this repository are welcome here: [`desktop/`](desktop), [`scripts/build/buildDesktopApp.mjs`](scripts/build/buildDesktopApp.mjs), [`test/desktop.mjs`](test/desktop.mjs), [`src/plugins/_core/`](src/plugins/_core) and [`assets/`](assets). The README says how to build and test it. Keep to [Endcord's contributing guide](https://github.com/Endcord/Endcord/blob/main/CONTRIBUTING.md) for the code style.
- **A plugin, or Endcord's settings?** Those pull requests go to [Endcord's repository](https://github.com/Endcord/Endcord).
- **Want a new plugin?** Ask on the [Endcord server](https://discord.gg/endcord).

Everyone taking part follows the [Code of Conduct](CODE_OF_CONDUCT.md).
